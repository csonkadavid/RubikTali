# RubicTali – hobbitárs-kereső Rubik-kockázáshoz

A RubicTali nem romantikus társkereső, hanem hobbitárs-kereső közös Rubik-kockázáshoz.

Fő funkciók:
- hely, szint, módszer, átlagidő és találkozási forma szerinti keresés
- interaktív térkép hozzávetőleges város/kerület szintű helyekkel
- státuszok: Most találkozna / Ma ráér / Ezen a héten / Rugalmas
- profilkártyák
- helyi profilmentés a böngészőben
- mobilbarát elrendezés

A státuszok kizárólag közös kockázást, gyakorlást és tanulást jelentenek.
